杨珂个人官网
================

打开方式
--------
双击文件夹里的 index.html，即可在浏览器中打开网站。
无需安装、无需注册，也不需要联网。

页面功能
--------
· 右上角太阳/月亮按钮：切换黑白主题，会自动记住选择。
· 右上角“中 / EN”按钮：切换中文和英文，会自动记住选择。
· 右上角“音乐”按钮：播放或暂停页面内置的原创轻柔音乐。
· 页面内容在手机、平板和电脑上都可以自适应显示。

如果想换成自己的照片
--------------------
可以把照片放进 assets 文件夹，再请家长或老师协助修改 index.html 中的
portrait-card 区域。当前版本使用“珂 / KE”姓名徽章，无需照片也能完整展示。

温馨提醒
--------
这个网站包含姓名、年龄、学校和年级，属于个人信息。若准备放到公开互联网，
建议先和家长或老师商量，并隐藏过于具体的身份信息。
